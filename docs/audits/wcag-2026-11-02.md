## Repairs

The dense painter retains its 12px baseline typography and compact spacing.
Checkbox inputs themselves are 24×24 CSS px; button targets have the same floor,
including the more specific card-navigation rule. A synthetic three-card probe
exposed 21 undersized-target occurrences before that override was corrected; a
permanent browser regression covers the short-label case at 320 and 1440px.
Checked boxes also have a contrasting state outline. Unitless line boxes scale
with text-only resize. Inputs, button inners/labels,
badges and alert messages grow and wrap instead of clipping. Narrow index-card
actions and lists use one column. Chrome uses opaque solid fills. Chart grids
and patient-point strokes meet the non-text threshold; percentile intervals use
contrasting outlines alongside the labeled reference curves. No clinical value,
action, theorem, specification, policy threshold or checker was removed.

The screen gate runs and enforces the physical matrix by default. Explicit
`EHR_ENFORCE_PHYSICAL=0` retains report-only diagnostics; explicit
`EHR_PHYSICAL_POLICY=0` disables the matrix. These settings enter whole-tree
receipt contexts. A bypass receipt cannot satisfy default enforcement. Physical
sample caches persist in `$TMPDIR/ehr-physical-samples`, or the path supplied by
`EHR_PHYSICAL_SAMPLE_CACHE`, under build/assertion/policy/browser/configuration
fingerprints. Findings never produce passing whole-tree receipts.

Large input lists retain file manifests and bounded sequential batches. Independent
malicious-control and presentation regression tests run once per invocation;
an explicitly empty cached manifest runs controls only. Every clinical tree still
gets both fidelity projects and all nine physical viewport/text cases, with
separate modal-free probes. Within each synchronous measurement, visibility and
rectangles are memoized;
these local caches reset for every viewport/state/focus sample. The 17 app
fixture states (162 matrix cases) produced byte-identical measurement data before
and after that optimization. Reports include total and per-batch elapsed
milliseconds. `audit-alert-policy.mjs --personas` now parses
its mode flag independently of the optional output directory.
