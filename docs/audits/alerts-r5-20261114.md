# High-alert notices and deployed action density

The high-alert rule and React density gate are **new specifications**. These
read-only checks preserve the retained recording. The [measurement contract](../methods/screen-validation.md#deployed-action-density-r5)
defines active targets, clipping, scroll regions, and fixed/sticky controls.

## Results

- Vendor-calibrated React limit: **57 targets** at 1440×900; first viewport peaks at 52.
- **0/33 retained revisions exceed 57**, including zero of the 18 nightly agent deployments.
- High-alert hardening refuses **25/33 unchanged revisions**. After migrating only obsolete optional-popup declarations in scratch, **20/33** still fail inline-notice retention.
- Native matrix: **15/15 accepted; 25/25 bad programs refused**, with replayable counterexample navigation.

The density collector checks **7,759 distinct trees** across 18 vendor programs
and 33 retained revisions with adult-allergic, pediatric and surgical fixtures.
It records **8,155** active/modal-free measurements. The diagnostic ceiling
during calibration was non-binding; the deployed gate enforces the measured
maximum of 57. These are static screen-state checks, not new clinical outcomes.
The complete per-program/per-screen counts, input hashes and refusal verdicts
are in [the derived JSON report](alerts-r5-20261114.json). No custom presentation
bundles occur in these retained programs.
